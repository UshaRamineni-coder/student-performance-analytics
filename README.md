# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System analyzes student academic performance using Python, NumPy, and Pandas.

## Objectives
- Calculate total and average marks.
- Assign grades based on average marks.
- Classify students as PASS or FAIL.
- Analyze subject-wise performance.
- Identify the top three performing students.
- Generate and export student performance results.

## Technologies Used
- Python
- NumPy
- Pandas
- Google Colab

## Project Files
- `Student_Performance_Analytics.ipynb` — Project code and analysis.
- `students.csv` — Original student dataset.
- `student_performance_results.csv` — Processed results.

## How to Run
1. Download the notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload and open the notebook.
4. Upload `students.csv` to the Colab session if required.
5. Run the notebook cells in order.

## Output
The system generates student totals, averages, grades, pass/fail results, class statistics, subject-wise analysis, and top-performing student details.
